# playwright-computer-use Skill

## Overview

Enables Claude computer use via Playwright browser automation. Provides stable, reliable GUI control for AI agents interacting with desktop applications.

## Installation

```bash
pip install -e .
```

## Running

```bash
python demo.py
```

## Core Capabilities

- Browser-based GUI automation using Playwright
- Desktop application control
- Screen capture and monitoring
- Cross-platform support (Windows, macOS, Linux)
- Reliable element interaction and detection

## Use Cases

- AI-powered desktop application control
- Automated GUI testing
- Cross-browser web interactions
- Desktop environment automation

## Key Features

- Playwright-backed stability for browser automation
- Computer use enabling for Claude models
- Robust element detection and interaction
- Multi-browser support (Chromium, Firefox, WebKit)

## Notes

This skill provides the most stable computer use capability when combined with Claude, leveraging Playwright's mature browser automation infrastructure.
