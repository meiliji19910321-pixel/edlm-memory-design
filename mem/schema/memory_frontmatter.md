# 记忆文件格式规范

## 标准格式

```markdown
---
name: memory-name
description: 一句话描述（用于向量索引和搜索）
type: identity | artifact | topic | memory
tags: [标签1, 标签2, 标签3]
trust_level: 1 | 2 | 3
version_chain: [v1, v2, v3]
topic_ref: ai-memory
created_at: 2026-05-08
updated_at: 2026-05-08
---

# 记忆正文内容
正文使用中文撰写。
可以是结构化的描述、决策、结论或观察。
```

## 类型说明

| type | 用途 | 示例 |
|------|------|------|
| `identity` | 用户角色、目标、偏好、约束红线 | 用户是滇池学院毕业生，计划做AI自媒体 |
| `artifact` | 我们创造的东西 | 代码文件、文档、方案设计 |
| `topic` | 话题索引 | "记忆框架"、"AI工具选型" |
| `memory` | 通用记忆碎片 | 观察、决策、偏好记录 |

## 标签规范

- 使用中文标签
- 标签用 `,` 分隔，外层用 `[]`
- 示例：`[记忆系统, 向量检索, AI工具]`

## 版本链规范

当 topic 类型记忆更新时，保留历史版本：
- `version_chain: [v1, v2]` 记录所有历史版本标签
- 实际内容存储在 `topic_versions` 表中
- 当前文件只保留最新版本

## 信任等级

| 等级 | 含义 | 注入策略 |
|------|------|---------|
| L1 | 新建，未验证 | 原文显示给用户，不自动注入上下文 |
| L2 | 被再次验证 | 摘要注入上下文 |
| L3 | 验证 3 次以上 | 仅提示存在，用户主动问才展示 |
